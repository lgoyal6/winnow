A smaller cache can still be a slower model.

Explore what quantization saves, what the process actually holds, and when the answers stop surviving. Every number comes from retained benchmark artifacts.

This is an interactive recording, not live inference. Memory and scored quality use Qwen2.5-7B; the separate decode study uses Qwen3-0.6B. No GPU, model download, account or API key is needed.

Logical bits versus resident bytes

The original cache kept both indices and a full-precision copy. Packing reduces persistent storage, with a decode throughput cost in this PyTorch-only experiment.
